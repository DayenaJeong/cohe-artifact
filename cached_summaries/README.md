# Cached Summaries

This directory contains anonymized aggregate summaries already reported in the manuscript. They are table-level values for reviewer verification and reuse of the COHE reporting format, not raw sample-level data.

The CSV files do not contain raw datasets, raw images, full proxy arrays, pretrained checkpoints, model weights, private paths, or author-identifying metadata. They are intended to verify paper-style tables and claim-tier mappings without rerunning expensive proxy generation or retraining.

Use `paper_table_index.csv` to map each cached summary to the corresponding manuscript table and verification script.
