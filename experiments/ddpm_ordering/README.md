# DDPM Ordering

This directory contains the ordering construction and training code, seed-level results, summary statistics, and the CPU statistics verifier for the DDPM ordering experiment.

Eighteen of 24 expected endpoint checkpoints are available in the [`v1.0-neurips2026` GitHub Release](https://github.com/DayenaJeong/cohe-artifact/releases/tag/v1.0-neurips2026). Random seeds 0–2 and Easy-to-Hard seeds 0–2 were not retained. All eight paired numerical records remain available. See [`docs/REPRODUCIBILITY.md`](../../docs/REPRODUCIBILITY.md) for the broader reproduction scope.
