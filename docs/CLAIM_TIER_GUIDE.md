# COHE reporting tiers

The final paper defines six tiers for a proxy–target–protocol setting. These are bounded reporting claims, not universal thresholds. The interface claim-card generator is a draft aid and does not implement the full precedence/calibration protocol.

| Canonical tier | Evidence/interpretation |
|---|---|
| Validated surrogate | All three gates pass for the stated setting. |
| Predictive validity only | Positive G1/G2 evidence, without a G3 pass; failed/unavailable G3 does not erase relational evidence. |
| Target-specific relation | Relational signal is confined to an auxiliary target, such as first-learning or GradNorm. |
| Operational-only effect | Positive G3 without matched positive G1 and G2; policy effect does not prove scalar-surrogate validity. |
| Weak evidence | Remaining incomplete/inconclusive support, including a G1-only alignment anchor. |
| No reliable transfer | Measured weak G2 or evaluated G3 without reliable benefit, without matched positive G1/G2 evidence. |

Apply Validated surrogate first, then Operational-only effect for positive G3 without both relational gates. For relational evidence, specialize to Target-specific relation when auxiliary-target-only; otherwise use Predictive validity only for positive G1/G2. Without matched positive G1/G2 use No reliable transfer for measured weak G2/evaluated unsuccessful G3. Remaining cases use Weak evidence. An unmeasured gate is not a measured failure. Appendix Table 13 is authoritative for complete definitions and permitted wording.
